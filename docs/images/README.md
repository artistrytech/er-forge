# README 用の画面イメージ

いずれも**仮置きの単色画像**（1600×900）。実際のスクリーンショットに差し替える。
**ファイル名は変えない**（変えるとリポジトリ直下の README.md 側も直す必要がある）。

| ファイル | 差し込み位置 | 撮る画面 |
|---|---|---|
| `erd-canvas.png` | 冒頭（タイトル直後） | ER図。テーブルが程よく並び、実線（物理FK）と破線（論理外部制約）が両方見えている状態 |
| `table-catalog.png` | 「テーブルカタログ」 | テーブル詳細画面。カラム表・制約・被参照が見えるもの |
| `column-dictionary.png` | 「論理名や注記は、逆生成しても消えません」 | カラム辞書（`#/columns`）。共通カラムの論理名・タグ・色が並んだ状態 |
| `introspect-diff.png` | 「DB からの逆生成」 | 逆生成の差分プレビュー。追加 / 削除 / 変更が並び、リネーム候補が出ているもの |
