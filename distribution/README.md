# ER 図管理ツール

DB スキーマの ER 図・テーブルカタログを、Git で管理しやすい形式で保守するツールです。

## 同梱物

| ファイル | 説明 |
|---|---|
| `erd-server.jar` | サーバーモード本体（Java 17 以上が必要） |
| `index.html` | ビューア。ブラウザで直接開ける単一の HTML |
| `erd.bat` / `erd.sh` | サーバーモードの起動スクリプト |
| `drivers/` | JDBC ドライバの置き場（初期は空。**全ワークスペース共通**）。逆生成画面から主要 DB のドライバをダウンロードできる。手動で JAR を置くことも可能（`drivers/README.txt` 参照） |
| `THIRD-PARTY-NOTICES.txt` | 同梱しているオープンソースソフトウェアの著作権・ライセンス表示 |
| `.gitignore` / `.gitattributes` | このディレクトリ配下の Git 運用設定。展開したらそのままコミットする |

## セットアップ

1. この ZIP の中身を、プロジェクトリポジトリの中の好きなディレクトリに展開する
2. 展開したディレクトリをそのままコミットする

   ```
   git add erd
   git commit -m "ER 図管理ツールを追加"
   ```

**ディレクトリ名は自由です**（このドキュメントでは `erd/` を例にします）。サーバーは自分が
置かれたディレクトリをプロジェクトルートとして動き、同梱の `.gitignore` / `.gitattributes` も
そのディレクトリからの相対で効くため、名前にも階層の深さにも依存しません。

`.gitignore` を書き足す作業はありません。除外すべきものは同梱の `.gitignore` がすべて持っており、
ツールが作るファイルは（個人データも含めて）すべてこのディレクトリの中に収まります。

## Git 管理の方針

**展開したディレクトリの中身は原則すべて Git 管理します**（`erd-server.jar` と起動スクリプトを含む）。
メンバーが `git pull` するだけで、全員が同じ版のツールとデータを使える状態にするためです。
バージョンアップは新しい ZIP を同じ場所に上書き展開し、その差分をコミットします
（**ディレクトリごと消してから展開し直さないでください。** スキーマデータと個人データも消えます）。

| 対象 | Git 管理 | 備考 |
|---|---|---|
| `index.html`・`erd-server.jar`・`erd.sh`・`erd.bat` | ✓ | `.gitattributes` でバイナリ指定し diff ノイズを抑制 |
| `workspaces.js`・`config.js`・`workspace-*/data/**` | ✓ | レビュー対象 |
| `drivers/README.txt` | ✓ | ドライバの置き方の説明 |
| `.local/` | ✗ | 個人データ。DB 接続情報（パスワードは明示保存時のみ）・逆生成の適用前バックアップ・個人設定 |
| `drivers/*.jar` | ✗ | ライセンスの都合で各自がダウンロードする |

## 使い方

### 編集者（サーバーモード。Java 17 以上が必要）

`erd.bat`（Windows）または `./erd.sh`（macOS / Linux）を実行すると、
`http://127.0.0.1:5321/` でサーバーが起動し、ブラウザが自動で開きます。

初回はワークスペースの作成画面が表示されます。ワークスペースは 1 データベースにつき 1 つ作成される想定で、
ID（英数・ハイフン・アンダーバー。省略時は `default`）と表示名を入力すると
`workspace-<ID>/` が作られます。複数の DB を扱う場合は、アプリタイトル横の
プルダウンからワークスペースの追加・切り替えができます。

続けてブートストラップ画面が表示されます。「サンプルデータを取り込む」を選ぶと、
約 30 テーブルの完成済みサンプルが `workspace-<ID>/data/` に書き出され、DB なしで機能を試せます。

編集後は `workspaces.js`・`workspace-*/data/**`
（ドライバ設定を変えた場合は `config.js` も）をコミット・プッシュしてください。

### 閲覧者（静的モード。Java 不要）

`git pull` して `index.html` をブラウザで開くだけです。
ER 図の閲覧・検索・テーブルカタログがそのまま使えます。

### スキーマ情報の書き出し（両モード共通）

ヘッダの **ツール（レンチ）→ [スキーマ情報を JSON で書き出す]** で、全テーブルの定義と
メタデータ（論理名・タグ・色・注記・論理制約）・リレーションを 1 つの JSON
（`schema-<ワークスペースID>.json`）にまとめて保存できます。ページ情報と ER 図の配置は含みません。
カラム辞書の論理名・タグは各テーブルの `meta.columns` にまとめて出力するため、受け取った側で
「テーブル個別 → 辞書」の解決をする必要はありません（辞書側の色は表示用の属性なので出力しません）。
出力は整形なしの最小サイズの JSON で、他のツールに渡すための形式です。
